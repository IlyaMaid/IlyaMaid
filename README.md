## / About Me

I'm a **Web Developer with over 3 years of commercial experience**
building, maintaining, and improving websites in the online
education industry.

My primary specialization is **Tilda development**. I turn
Figma designs into responsive, functional websites using
Tilda Zero Block, HTML, CSS, and JavaScript.

My commercial experience includes:

- Building landing pages and multi-page websites from Figma designs.
- Creating responsive layouts for desktop, tablet, and mobile.
- Developing custom JavaScript functionality and interactive elements.
- Integrating forms with CRM systems, APIs, and webhooks.
- Troubleshooting, maintaining, and improving existing websites.

Alongside commercial work, I'm expanding my skills in
**fullstack development**, working with backend APIs,
frontend interfaces, databases, and deployment.

My main personal project is currently **TastePlanner**.
I'm also interested in local LLMs, RAG systems, and automation.
